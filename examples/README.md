# Examples

`haruka/` is an original, rights-clean sample character used to demonstrate
the full econte pipeline end to end (storyboard → keyframes → approval →
clips → ingest). It lands in Phase P4 of `docs/implementation-plan.md`.

**Contribution rule:** examples in this directory must only ever contain
original characters/assets we hold the rights to, or CC0 material. No fan
art, no real-person likenesses, no third-party copyrighted characters —
see `CONTRIBUTING.md`.
